## 1. 设计原则

### 1.1 核心调性
- **温暖 + 干净**：开饭是一款家用做饭 App，视觉要传达"亲切、烟火气"但不"油腻"。
- **高级感**：避免过于卡通 / 手绘的廉价感；插画用线条，配图用真实摄影风。
- **信息清晰**：做饭时是高频阅读场景，**字号、对比度、行距优先**，不追求装饰性。
- **克制使用主色**：亮橙 #FF7A45 是品牌色，但**只在关键 CTA / 错误状态 / 当前活动指示**上使用，常规按钮用棕黑。

### 1.2 适配原则
- **只做移动端竖屏**，不维护横屏。
- 主设计稿：**375 × 812**（iPhone X 标准）。
- 适配范围：**320px – 430px**（覆盖 iPhone SE ~ iPhone Pro Max）。
- 不做平板适配。

### 1.3 字体与排版原则
- **字号优先**：阅读距离 60cm – 1m，所有可读文字必须 ≥ 16px。
- **行高优先**：正文行高 1.6 – 1.8，比一般 App 更宽松。
- **数字与中文之间必须有空格**（如"腌制 15 分钟"）。
- **配色优先**：深棕黑 `#2A2520` 主文字色，对比柔和不刺眼。

## 3. 组件库（Component Library）

> 所有组件的设计与 PRD §3.3.3 按钮规范一致。组件代码采用 Vue 3 + `<script setup>` 风格。

### 3.1 Button 按钮

#### 3.1.1 主按钮（PrimaryButton）— 黑色/棕黑色
- 用途：主要操作（下一步、发送给开饭、换一批菜、完成）
- 样式：
  ```
  高度：56px
  圆角：--radius-md (8px)
  背景：--color-text-primary (#2A2520)
  文字：--color-text-inverse (白)
  字号：--text-body (18px)
  字重：--font-medium (500)
  内边距：水平 24px
  ```
- 状态：
  - 默认：实心深色
  - 按下：`opacity: 0.85` + 200ms 过渡
  - 禁用：`background: --color-bg-tertiary`，`color: --color-text-disabled`

#### 3.1.2 次按钮（SecondaryButton）— 浅色气泡
- 用途：次要操作（上一步、添加图片）
- 样式：
  ```
  高度：56px
  圆角：--radius-md (8px)
  背景：白色 + 浅边框（--color-border）
  文字：--color-text-primary
  字号：--text-body (18px)
  边框：1px solid --color-border
  ```
- 宽度：约 30% 屏幕宽

#### 3.1.3 强调按钮（AccentButton）— 亮橙（仅限关键场景）
- 用途：**仅限**关键 CTA（首页"上传截图"、错误重试）
- 样式：
  ```
  高度：56px
  圆角：--radius-md (8px)
  背景：--color-primary (#FF7A45)
  文字：白色
  字号：--text-body-lg (24px)
  ```
- **绝不在普通导航按钮上使用**

### 3.2 Card 卡片

#### 3.2.1 菜品卡片（DishCard）— 关键组件
- 用途：方案页、结果页展示菜品
- 布局：**左图右文**（参考原型图）
- 样式：
  ```
  整体：白色底 + --shadow-card
  圆角：--radius-lg (12px)
  内边距：--space-4 (16px)
  间距：卡片之间 --space-4 (16px)
  ```
- 子区域：
  - **左侧图片**：
    - 尺寸：96 × 96px
    - 圆角：--radius-md (8px)
    - 背景：--color-bg-secondary
    - object-fit: cover
  - **右侧文本**：
    - 菜名：`--text-h2` (24px)、`--font-semibold`
    - 描述：`--text-body-sm` (16px)、`--color-text-secondary`、单行省略
    - 时间：`--text-caption` (14px)、`--color-text-tertiary`
  - **右侧箭头**：
    - 位置：垂直居中
    - 颜色：`--color-text-tertiary`
    - 尺寸：20px

#### 3.2.2 通用卡片（GenericCard）
- 圆角 12px、白底、`--shadow-card`、内边距 16px

### 3.3 Input 输入框

- 高度：48px
- 圆角：`--radius-md` (8px)
- 背景：`--color-bg-tertiary` (奶白)
- 边框：无（用背景区分）/ 或 `1px solid --color-border`（focus 时）
- 文字：`--text-body` (18px)
- 占位符：`--color-text-tertiary`

### 3.4 TopBar 顶栏（固定）

> 关键：所有页面的顶栏**结构一致**，只是中间标题文字和右侧图标不同。

- 高度：44px（含安全区 24px），即内容区 44px + 状态栏 24px
- 背景：白色（带 `--color-border` 下边框 1px）
- 层级：`--z-sticky`
- 结构：
  ```
  ┌────────────────────────────────┐
  │  ‹      [菜名/页面标题]      ··· │
  └────────────────────────────────┘
  ```
  - 左侧：返回箭头（仅在非首页显示），位置 12px 左内边距
  - 中间：页面标题，居中，`--text-body` (18px)、`--font-medium`
  - 右侧：更多菜单（···），位置 12px 右内边距

### 3.5 BottomBar 底部固定区

- 高度：动态（按内容），但最小 80px
- 背景：白色（带顶部 1px `--color-border`）
- 层级：`--z-fixed`
- 内边距：水平 16px，上下 12px
- 安全区：底部再加 16px 留 iPhone Home indicator

### 3.6 TabBar 底部 Tab（仅首页）

- 高度：56px（含安全区 16px）
- 背景：白色
- 边框：顶部 1px `--color-border`
- 三个 Tab：**首页 / 收藏 / 厨房**
- 选中：图标和文字用 `--color-text-primary`
- 未选中：图标和文字用 `--color-text-tertiary`
- 图标 24px，文字 12px

### 3.7 ProgressBar 进度条（步骤页专用）

- 高度：6px
- 圆角：`--radius-full`
- 背景：`--color-bg-tertiary`
- 进度：`--color-primary` (亮橙，**当前活动指示才用**)
- 分节显示：总节数 = 步骤数，每节用 1px `--color-bg` 间隔
- 层级：`--z-sticky`，紧贴顶栏下方

### 3.8 倒计时大卡片 + 胶囊

- 大卡片：
  - 位置：顶部居中（顶栏下方）
  - 宽度：屏幕宽 - 32px 内边距
  - 高度：约 120px
  - 圆角：`--radius-xl` (16px)
  - 背景：`--color-primary` 渐变到 `--color-primary-light`
  - 文字：白色
    - 名称：`--text-body` (18px)
    - 数字：`--text-display` (36px)、`--font-bold`
- 胶囊：
  - 位置：右上角
  - 高度：36px
  - 圆角：`--radius-full`
  - 背景：`--color-text-primary` (深色)
  - 文字：白色
    - 数字：`--text-body` (18px)、`--font-bold`
    - 名称：`--text-caption` (14px)
  - 多个胶囊重叠：每个胶囊 `transform: translateX(-N * 40px)` 堆叠

### 3.9 Toast / 全屏浮层

- 全屏浮层（倒计时结束）：
  - 背景：`rgba(42, 37, 32, 0.85)` 半透明
  - 内容：摇晃的闹钟图标 + "知道了" 按钮
  - "知道了"按钮：高度 64px，宽 200px，亮橙实心

#### 4.1.2 详细规范

- 行高：1.5
- 居中显示

**副标题**

- 颜色：`--color-text-secondary`
- 居中
- 上边距：12px

**底部 Tab（纯文字）**
- 三个 Tab：首页 / 收藏 / 厨房
- **纯文字，无图标**（和 PRD §3.6 不同，以实际效果图为准）

## 6. 动效规范

### 6.1 全局动效原则
- **短而精**：所有过渡 < 600ms
- **有意义**：每个动效都有功能目的（指示、引导、反馈）
- **不打断**：避免全屏闪烁、避免不可中断的动画

### 6.2 关键动效清单

| 动效 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 按钮按下 | 150ms | ease-default | opacity 1 → 0.85 |
| 卡片浮现 | 400ms | ease-emphasis | 从下方淡入 + 缩放 0.9 → 1 |
| 页面切换（左右） | 300ms | ease-default | 横向滑动 |
| 食材图标循环 | 800ms/次 | linear | 切换时短暂缩放 |
| 食材图标落停 | 600ms | ease-emphasis | 弹性落下 |
| 倒计时大卡片 | 400ms | ease-emphasis | 缩放进入 |
| 倒计时大卡片→胶囊 | 600ms | ease-emphasis | 右上角缩放 |
| 进度条填充 | 400ms | ease-default | 当前节高亮 |
| 文字光效扫过 | 1500ms | linear | 循环 |
| 庆祝动画 | 2000ms | ease-emphasis | 星星粒子爆发 |

### 6.3 性能约束
- 优先使用 `transform` 和 `opacity` 做动画（GPU 加速）
- 避免 `width/height/top/left` 动画
- 移动端启用 `will-change` 但要节制
- 食材图标切换用 `requestAnimationFrame` 同步

## 7. 响应式规范

### 7.1 适配范围
- 最小：320px（iPhone SE 1）
- 最大：430px（iPhone Pro Max）
- 设计稿基准：375px

### 7.2 缩放策略
- **使用 rem 单位**：1rem = 16px（基准）
- **根字号动态计算**：`html { font-size: calc(100vw / 375 * 16) }` 让 1rem 随屏幕缩放
- 但**圆角、阴影、内边距用 px**（避免失真）

### 7.3 不适配场景
- 不支持横屏
- 不支持平板
- 不支持 Windows / Mac 桌面浏览器（用响应式提示用户用手机访问）

---

## 8. 可访问性

- 所有可点击元素 ≥ 44 × 44px（厨房场景点击友好）
- 文字与背景对比度 ≥ 4.5:1
- 表单元素有 label
- 动效支持 `prefers-reduced-motion: reduce`（降级为淡入淡出）
- 图片有 alt 属性

## 9. 资源规范

### 9.1 图标
- 风格：线性图标（1.5px 描边，圆角端点）
- 来源：自建 SVG / 第三方库（如 Iconify）
- 颜色：继承父元素 `currentColor`

### 9.2 食材图标
- 用户提供至少 20 种常见食材的图标
- 风格：圆润、可爱但不过度卡通
- 格式：SVG，96 × 96px
- 背景：透明

### 9.3 菜品配图
- 1:1 比例，**纯白底**
- 高级白盘 + 斜俯拍
- 真实摄影光线
- 由 **MiniMax image-01** 批量生成
- 存储：阿里云 OSS

### 9.4 装饰背景
- 首页手绘食材装饰：线条插画
- 颜色：`--color-text-tertiary` + 透明度 0.18
- 位置：屏幕四角
- 避免遮挡文字
